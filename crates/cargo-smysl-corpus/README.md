# cargo-smysl-corpus

Units, labels and the `x.code` schema. Part of [`cargo-smysl`](https://github.com/vulogov/rust_smysl), a cargo subcommand that records **why** Rust code changed and keeps the record honest.

Builds a commit's decisions, prerequisites, alternatives and consequences into smysl units, assigns every label, source and status, and checks each quote against the commit. Model-free by design.

Measured figures, design rules and the full documentation are in the [repository](https://github.com/vulogov/rust_smysl).
