# cargo-smysl-bench

Measuring extraction against a person's labels. Part of [`cargo-smysl`](https://github.com/vulogov/rust_smysl), a cargo subcommand that records **why** Rust code changed and keeps the record honest.

Label templates and reading sheets, adjudication, and precision and recall per kind — so an operator can measure the model they chose, on the commits they have.

Measured figures, design rules and the full documentation are in the [repository](https://github.com/vulogov/rust_smysl).
