# cargo-smysl-verdict

`check`, fact matching, the status policy and staleness. Part of [`cargo-smysl`](https://github.com/vulogov/rust_smysl), a cargo subcommand that records **why** Rust code changed and keeps the record honest.

What a change contradicts, what a claim is covered by, what a single run is allowed to conclude, and which recorded reasoning rests on code that has moved.

Measured figures, design rules and the full documentation are in the [repository](https://github.com/vulogov/rust_smysl).
