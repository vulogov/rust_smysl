# cargo-smysl

The cargo subcommand. Part of [`cargo-smysl`](https://github.com/vulogov/rust_smysl), a cargo subcommand that records **why** Rust code changed and keeps the record honest.

Install it with `cargo install cargo-smysl`, then run `cargo smysl doctor`. The other crates in this workspace are its parts; this is the one to install.

Measured figures, design rules and the full documentation are in the [repository](https://github.com/vulogov/rust_smysl).
