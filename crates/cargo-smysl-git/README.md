# cargo-smysl-git

Reading commits with `gix`. Part of [`cargo-smysl`](https://github.com/vulogov/rust_smysl), a cargo subcommand that records **why** Rust code changed and keeps the record honest.

A commit's message and its files before and after, read as a library. The tool never runs the `git` binary.

Measured figures, design rules and the full documentation are in the [repository](https://github.com/vulogov/rust_smysl).
