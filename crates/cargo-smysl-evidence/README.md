# cargo-smysl-evidence

Tests as measured evidence. Part of [`cargo-smysl`](https://github.com/vulogov/rust_smysl), a cargo subcommand that records **why** Rust code changed and keeps the record honest.

A deterministic shortlist of tests that might bear on a claim, the runner that records what they did, the edges that follow, and the opt-in mutation gate.

Measured figures, design rules and the full documentation are in the [repository](https://github.com/vulogov/rust_smysl).
